기업가치평가 · DCF / WACC
일반 비금융기업의 연간 공시 기준. 기준일은 선택 사업연도 말입니다. 금액은 억원, 주식 수는 실제 주 단위, 주가는 원 단위입니다. 미래 가정은 사용자 입력이며 시장금리는 수동 입력이며 주가는 주가·시장지표 메뉴에서 확인 후 반영할 수 있습니다.


1. 5개년 영업현금흐름 가정
FCFF = EBIT × (1 − 세율) + 감가상각비 − CAPEX − 영업순운전자본 증가액. 운전자본 증감은 매출 증감액 × 가정 비율. 세금효과는 단순화하며 결손금은 별도로 고려하지 않습니다.


2. 자본비용 · CAPM
목표 부채비중은 시장가치 기준 D/(D+E) 가정. WACC = Ke × (1−부채비중) + Kd × (1−세율) × 부채비중. 무위험수익률·시장위험프리미엄·베타는 직접 입력합니다.


3. 영업가치 → 보통주 지분가치
이자부채에는 필요한 경우 리스부채 포함. 비영업자산은 영업에 필요하지 않은 현금·투자자산 등이며 중복 계산 금지. 비지배지분·우선주 등 다른 청구권을 차감합니다. 각 금액이 없으면 확인 후 0을 직접 입력하세요. 기말 보통주 발행주식 수에서 자기주식을 제외한 수량을 사용합니다.


4. 상대가치 지표 (선택 입력)
보통주 귀속 순이익 및 장부가치, 실제 감가상각비는 원문 확인 후 입력합니다. 예상 주가가 아니라 입력한 기준 주가로 시장 PER·PBR·EV/EBITDA를 계산합니다. 비교기업 배수는 사용자가 직접 입력하며 자동 수집하지 않습니다.


가정을 입력한 후 계산하세요.
